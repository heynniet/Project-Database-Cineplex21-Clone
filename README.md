# 📚 Library Management System (SSIP Project)

This project is a **Library Management System** designed to support book borrowing, donation management, and administrative operations.  
It aims to streamline library processes for both users and administrators by providing an intuitive and structured system.

---

## 📌 Overview

The Library Management System allows users to:
- Browse and search for books
- Borrow and return books
- Donate books to the library

Administrators can:
- Manage book data
- Monitor borrowing activities
- Manage users and donations
- Maintain overall library resources efficiently

## 🛠️ Technologies Used
- PHP – Backend development
- MySQL – Database management
- XAMPP – Local server environment
- HTML & CSS – Frontend structure and styling
- JavaScript – Basic interactivity

## 🚀 How to Run the Project
- Clone the repository:
    git clone https://github.com/heynniet/Project-SSIP-Library-System.git
- Move the project into the XAMPP htdocs directory:
    htdocs/Project-SSIP-Library-System
    Start Apache and MySQL from XAMPP Control Panel.
- Import the database:
    Open phpMyAdmin
    Create a new database
    Import the .sql file from the database/ folder
    Configure database connection in the config/ folder.
    Open the project in your browser:
    http://localhost/Project-SSIP-Library-System
